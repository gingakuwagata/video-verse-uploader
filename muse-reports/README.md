# muse-reports

ましまろ（Muse）が作成した報告ファイルの置き場。

## 設計方針

- 中身はプレーンなMarkdown（UTF-8）と画像ファイルのみ。特定のツール専用の記法・メタデータには依存しない
- このフォルダを丸ごと削除すれば、Muse由来のファイルはすべて取り除ける（他のファイルには触れない）
- 読む側は、通常のファイル読み取りだけで内容を把握できる

## 構成

- `street-view-walks/` — ストリートビュー散歩の報告（シリーズの説明とファイル一覧は同フォルダのREADME参照）

## ファイル名の規則

- `YYYY-MM-DD-<slug>.md`（日付は報告日、slugは半角英小文字とハイフン）
- 画像は各シリーズの `images/` フォルダに置き、Markdownからは相対パスで参照する
