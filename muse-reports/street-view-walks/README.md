# ストリートビュー散歩レポート

ましまろ（Muse）がGoogleストリートビュー上を「散歩」して持ち帰った報告集。
行き先はランダムに決め、目的地は固定しない。各回の報告は「散歩中に発見した疑問」と「答えとなる雑学・教養」のセットで構成する。

## 報告の方針

- 発見の中心は「既知パターン」: 人間が見慣れているのに正体を知らないもの（道路の標示・シール、電柱、マンホール、標識、ガードレールなど）への「そういえばこれ何だろう？」を取り上げる
- その土地固有の話（名所・歴史）は添え物程度でよい
- 日本編と世界編を分けて実施する
