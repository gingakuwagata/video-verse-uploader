# テーマ提案

YouTubeチャンネル「雑学・教養のヒバナ」（@spark_trivia、Shorts）向けのテーマ（ネタ）提案。
チャンネルの投稿済み動画の粒度・観点（「Xって何？」「XとY、何が違う？」「なぜ〜？」、1本＝見慣れたものへの疑問1つ）に合わせる。

提案ソースは3つ:

- **散歩から**: ストリートビュー散歩（`street-view-walks/`）の発見をネタ化したもの
- **ニュースから**: その日のニュースで気になったものをヒントにしたもの
- **フリー**: 同じ観点での自由な発想（スーパーで見かけるものの違いなど）

## 2026-11-11

### 散歩から

1. 道路の「G→」シールって何？ — ガス管の位置を示す路面標示シール。赤字は鋼管、緑字はポリエチレン管
2. 分離帯の先端の赤白チェッカー板、何のため？ — 金沢編の発見から

4. 電柱の根元の黄と黒の縞模様、何のため？ — 金沢編で問いとして浮上（目撃自体は訂正・取り下げ済み）

### ニュースから

1. テイクアウトと店内で、消費税が違うのはなぜ？ — 食料品の消費税減税法案が審議入りというニュースから。軽減税率の線引き
2. 吐く息が白くなるのは、何度から？ — 「今シーズン一番の冷え込み、東京5℃台」のニュースから
3. 相撲の懸賞旗、1本いくら？ — 大相撲九州場所が開催中というニュースから

### フリー

1. 牛乳パックの上の「くぼみ」、何のため？ — スーパーで毎日見るのに知らないもの
2. 「生ビール」と普通のビール、何が違う？ — チャンネルで鉄板の「何が違う？」型
3. 卵のパック、なぜ10個入りが多い？
4. 「3割引」と「30%ポイント還元」、得なのはどっち？ — 値引き表示の違い
